Процент задаётся на подгруппу, не на всю группу. На одном листе строка дисков получает свой %, строка колодок — свой. Пустой конкурент не участвует.

Марки и модели авто

По столбцу «Разновидность» программа ставит автопарк и ценовой сегмент. Модель из цифр («3», «600») ищется только вместе с маркой. Сегмент разновидности — самый высокий из найденных моделей: Land Cruiser поднимает строку в премиум, Гранта остаётся в бюджетном.

Как распознались прайсы

Папка внутри «Прайсы» — поставщик. Бренды — с листа 02 позиционирования
Снимки для динамики: Данные/Прайсы/12.10.2026/Armtek/файл.xlsx. Файл валюта лежит прямо в «Прайсы»: в шапке даты, в строках USD, EUR, JPY. Без папки-даты поставщик по-прежнему Данные/Прайсы/Armtek. Город по-прежнему из имени файла: TissEKB — Екатеринбург. Цена — столбец, где почти все значения числа и название не похоже на наименование. Ручная настройка одного файла применяется ко всем прайсам с теми же названиями столбцов. «Выгрузка по кроссам» собирает один файл: наш артикул, кросс и цена поставщика.

# Ценовой анализ

Программа для Windows (батник + Python), которая из сырых выгрузок 1С собирает итоговый
отчёт ценового анализа по шаблону `примеры/шаблон/ADVICS_тормозные_диски.xlsx`:
товар → кросс-артикулы конкурентов → категории и цены → ВР, суммы → цены конкурентов и отклонение.

Архив этой сборки лежит в файлах проекта: `Файлы/ценовой-анализ.zip`.

## Как пользоваться

1. Один раз установите [Python 3](https://www.python.org/downloads/) — при установке отметьте
   **Add python.exe to PATH**. Модуль `openpyxl` батник поставит сам при первом запуске.
2. Разложите файлы (имена любые, `.xlsx` / `.xls` / `.csv`):
   - `Данные/Кроссы` — один «Кроссы свод» на все группы;
   - `Данные/Прайсы` — прайсы поставщиков. Для динамики цен папка называется датой, внутри — папки поставщиков: `Данные/Прайсы/12.10.2026/TISS/TissEKB.xls`. Файл `валюта` лежит прямо в `Данные/Прайсы`: в шапке даты, в строках коды валют и курс. Без даты по-прежнему `Данные/Прайсы/TISS/`;
   - `Входящие` — общие ПСТ, СБС и Продажи на весь ассортимент. Если файл есть здесь, он важнее такого же в папке группы. Если его нет — берётся файл группы. Справочник ОЕМ смежных марок можно положить сюда, в `Выгрузки 1С`, в папку группы или рядом с программой;
   - `Данные/Группы/ADVICS — Тормозные диски` — АЦПКД этой группы и, если нет общих, свои ПСТ, СБС и Продажи. На каждую группу бренда своя папка.
     «Товар в пути» может быть один на всю компанию: положите его в папку группы — программа подставит его остальным группам, у которых своего файла нет.
     Фильтры, кроссы, источники и пороги запоминаются. Кнопка «Сбросить к стандарту» в «Настройках отчёта» возвращает стандарт: все товары, цены из АЦПКД и прайсов, кроссы по подсказке.
   ГЗ, скидки и позиционирование правятся во вкладке «Настройки». Пока в «Группы» пусто, программа читает `Входящие`.
3. Запустите `Запуск.bat` — откроется окно программы. Пока оно нужно, не закрывайте чёрное окно запуска.
   В шапке окна написано «сборка 16 окт, 2». Если этой надписи нет, запущена старая папка.
   В окне четыре раздела:
   - **Отчёты** — отчёт по группе и «Распродажа и оверсток». Отчёт всегда полный и строится от ПСТ; цены конкурентов — из прайсов последней даты выгрузки, ненужный файл можно выключить. У группы четыре вкладки: **«Цены и рекомендации»** (слева пороги ползунками, справа цифры и графики «сейчас → после», пересчитываются сразу), **«Почему мало цен»** (воронка от товара до цены по каждому конкуренту и где теряется больше всего), **«Таблица»** (первые строки отчёта) и **«Настройки отчёта»** (подгруппы, фильтры, прайсы, кроссы, источники);
   - **Прайсы** — как конкуренты меняют цены: графики и цифры по датам, городам, брендам и группам, связь с курсом, выгрузка цен в Excel для макроса;
   - **Данные** — папки, календарь прайсов «поставщик × дата», как распознан каждый файл, написание брендов;
   - **Настройки** — справочники и внизу «Диагностика»: какая сборка запущена, папка результата и есть ли там `Разбор.txt`.
   Пока программа читает папку, на экране окно загрузки: этапы по порядку — папка и кэш, чтение Excel, распознавание прайсов, группы и цены. У каждого этапа видно, сколько он занял, у текущего — файл и сколько осталось. Этап, который не понадобился (всё взято из кэша), так и помечен. Если этап падает, текст ошибки остаётся у него, кнопка «Повторить» запускает чтение снова.
   Кнопка **«Обновить данные»** перечитывает папки без перезапуска. Файл открывается заново, только если изменились его дата или размер; остальное берётся из `Программа/кэш`. Повторный заход в группу и смена фильтра не разбирают ПСТ и прайсы заново: цифры те же, считается только то, что изменилось. Прайсы разбираются один раз на все группы, а не заново для каждой: «Все группы» на больших прайсах не упирается в память. Большие .xlsx читаются потоком, в 3–4 раза быстрее; если книга устроена непривычно, она читается прежним способом. Новые файлы читаются в нескольких процессах сразу. От прайса в памяти держится только начало листа: цены собраны и лежат в кэше. Скрытые листы ПСТ, СБС и Продажи пишутся готовым XML — содержимое то же, а файл группы собирается в разы быстрее.
4. Слева — очередь групп. Зелёная строка — нашлись ПСТ, СБС, Продажи и АЦПКД. Серая — коротко написано, чего не хватает.
   **«Все группы»** кладёт файлы Excel только по зелёным строкам. `Разбор.txt` пишется по каждой группе из списка, в том числе серой и без цен. **«Сформировать отчёт»** — ту, что открыта, даже если набор неполный.
   Файл появится в `Результат` и откроется сам: «Целевые группы» — диски и колодки ADVICS и AVANTECH, фильтры AVANTECH и DOUBLE FORCE, если есть цена конкурента. По ним судим объём и продажи. «Мелкие группы» — цена конкурента есть у любой другой группы. «Нет цен» — цены конкурента нет. `Разбор.txt` остаётся в самой папке `Результат`.

## Что программа узнаёт в папке

Документ определяется по названиям столбцов, а не по имени файла.
Если документов одного вида несколько, берётся самый свежий.

| Документ | Что из него берётся |
| --- | --- |
| ПСТ | товары, группа заказа, категории, закупка и её валюта, МО, разновидность, ABC, оверсток, вывод из ассортимента |
| Продажи | количество (шт) и сумма продажи, период — из шапки отчёта |
| СБС | остаток и себестоимость (себестоимость / кол-во) |
| Товар в пути | «Заказано, шт» из колонки «Итого». В отчёте — «В пути, шт» сразу после остатка и «Потенциал, шт» = остаток + в пути. Артикул ищется без точек и дефисов |
| АЦПКД | цены конкурентов по поставщикам, а также МО, Кат. А, СБС, остаток, ABC — если выбран этот источник |
| Кроссы свод | кроссы с признаком «Использовать для сравнения цен» |
| ОЕМ | артикул, торговая марка и «ОЕМ-номер». Имя вида «ОЕМ ТМ+ТМ Категория». Папка: «Входящие», «Выгрузки 1С», группа или корень программы |
| Скидка для клиентов | «Общие скидки» по подгруппе + группе заказа + ТМ. Нет файла — из настроек |
| ГЗ | коэффициент группы заказа для «СБС план». Нет файла — из настроек |
| Позиционирование | конкуренты для ТМ + подгруппы и какие бренды мониторит каждый поставщик. Нет файла — встроенное |
| Прайсы поставщиков | всё, что не узнано как документ 1С: бренд, артикул, цена, наличие |

### Прайсы

У каждого поставщика (и даже у одного поставщика по разным городам) свой формат, поэтому:

- программа сама ищет строку шапки и столбцы артикула, цены, бренда и наличия — по названиям и по содержимому. Узнаёт и «Произв.», «Номер запчасти», «№ ПРОИЗВ.», «Ост.», английские articul / brand / price;
- файл без шапки (Armtek, Форум-Авто .csv) читается с первой строки, даже если шапкой отмечена строка с ценой. Такая «шапка» не становится сохранённой формой для других файлов;
- столбец бренда проверяется по содержимому. Если в нём модели машин («CITROEN C5, PEUGEOT 407», «TOYOTA Camry 06->»), а рядом столбец с брендами из кроссов, бренд берётся оттуда и это видно в замечании. У файла, настроенного вручную, программа только предупреждает;
- если соседний столбец совпадает с кроссами заметно чаще выбранного артикула (у Ivers «Кросс-номера» и «Номер запчасти»), в замечании это написано: проверьте столбец артикула. Если в наличии почти везде 1, а рядом столбец с разными количествами, — это кратность: у файла без шапки берётся остаток, иначе предупреждение;
- поставщик берётся из имени папки внутри `Данные/Прайсы` и сверяется с поставщиками из позиционирования. Файл прямо в «Прайсы», без папки, по-прежнему читается по имени: `TissEKB.xls` → TISS · Екатеринбург. Город и в папке берётся из имени файла: коды (EKB, SPB1, NVS, VLK, KRD2), русские названия и сокращения («Прайс Армтек_Иркутск», «_ЕКБ», «_НСК») и город в скобках — он важнее: `BergIRK(Чита)` — Чита. Свои коды задаются в «Настройках» → «Города в именах прайсов» (например, RZD — Раздольное). Если город указать у файла руками («Править» → «Город / склад»), он запоминается для этого же файла поставщика на все следующие даты: у Rossko «118482.xlsx» — Южно-Сахалинск; дата и время выгрузки в имени («BERG_IRK_20261015_040019») не мешают. Динамика сравнивает цены одного поставщика и города, поэтому файлы одного склада лучше называть одинаково во все даты;
- раздел **«Данные»** показывает календарь «поставщик × дата» (зелёный — распознан, жёлтый — замечание, красный — проблема, серый — прошлая дата ещё не разобрана) и файлы по датам: последняя дата открыта, прошлые свёрнуты. Нажмите на клетку — откроются её файлы. **«Обновить данные»** перечитывает папку. **«Править»** меняет шапку и столбцы. Ручная настройка с названиями столбцов сразу действует на все прайсы с такой же шапкой, без отдельной галочки. **«Устройство прайсов»** кладёт `Результат/Устройство прайсов.txt`. **«Проверка по кроссам»** кладёт `Результат/Кроссы и цены.xlsx`: наш артикул, кросс-артикул, поставщик, город и цена. Кроссы «Да» без цены — на листе «Без цены»;
- цена узнаётся только если в столбце не меньше 80% чисел и заголовок не похож на наименование. Наименование из чисел не берётся. Если чисел в цене меньше 90%, строка файла помечается — это повод нажать «Править»;
- если столбцов с ценой несколько, берётся оптовая: сначала «ОПТ» («Цена опт», «Оптовая»), розница («розн», РРЦ, МРЦ) — только если другой цены нет;
- блок **«Написание брендов»** в «Данных»: бренд в прайсе или в кроссах похож на конкурента, но не совпал («Kashiyama Japan», «G-Brake Germany», опечатка «BREMBBO»). Похожесть — целым словом: «HERMANN» не считается похожим на MANN, строки с моделями машин не предлагаются. «Считать как …» заводит синоним — цены этого написания идут в сравнение. Можно отметить несколько и применить пачкой. «Не тот бренд» убирает подсказку навсегда; отклонённые видны внизу блока и возвращаются кнопкой «вернуть». Сама программа ничего не склеивает без спроса;
- файл сравнивается с прошлой датой того же поставщика и города. Медиана цены бренда ушла больше чем на треть — замечание: похоже, поставщик поменял формат и столбец цены не тот. «Цен меньше» и «пропал бренд» — синяя справка, не ошибка: так бывает, когда в этот день у поставщика и города меньше файлов. Сводки прошлых дат копятся в `Программа/кэш/price_stats.json`;
- раздел **«Прайсы»** — динамика цен конкурентов. Только позиции из наших кроссов и бренды из позиционирования; одна позиция — поставщик + город + бренд + артикул. По умолчанию последняя выгрузка сравнивается с предыдущей; кнопки «Неделю назад», «Месяц назад», «Первая дата» включаются, когда история накопится. Изменение считается только по позициям, которые есть в обе даты у того же поставщика и города; пропавшие и новые — отдельно. На экране: индекс цен по брендам за все даты с курсом пунктиром; «Кто поменял цены» — доля позиций вверх и вниз по брендам; «Где поменял» — категория → группа → подгруппа (нажатием вглубь) и самые большие изменения по позициям; карта «поставщик × город»; распределение изменений; главное за период; связь шагов цены с шагами курса с запаздыванием до 4 дат (от 6 дат выгрузки);
- **«Выгрузка цен в Excel»** кладёт `Результат/Цены конкурентов по датам.xlsx` для макроса: одна строка — цена позиции из кроссов у поставщика и города на дату. Столбцы: дата, поставщик, город, файл и строка в нём, бренд и артикул как в прайсе и для поиска, цена, наличие, прошлая дата и цена на неё, изменение, наш ТМ, артикул, код, наименование, категория, группа, подгруппа, кросс «Да», мониторит ли поставщик бренд, «Первая строка цены» (если кросс у нескольких наших товаров, единица только у первой — суммы не задваиваются). Листы «Даты и файлы», «Курсы» и «Проверка» — 50 случайных цен рядом с целой строкой исходного файла, чтобы глазами сверить разбор;
- отчёт и проценка берут прайсы только последней даты; старые даты — для динамики. При запуске прошлые даты не читаются: они дочитываются, когда открываете «Прайсы» (или кнопкой в календаре), и тогда же появляются в «Данных». Ручные столбцы, указанные на прошлой дате, всё равно учат следующие даты поставщика. Если все файлы последней даты выключены, отчёт, как и раньше, берёт предыдущую дату. Смена фильтра не блокирует экран: пересчёт идёт один, лишние клики не встают в очередь;
- если не угадала — нажмите **«Править»** в «Данных» или **«Настроить»** в «Настройках отчёта»: окно настройки открывается прямо под строкой файла. Выберите строку шапки и столбцы из списка (рядом примеры значений), справа сразу видно, что получится — по первым 400 строкам, без чтения всего файла. После «Сохранить» заново разбираются только этот файл и файлы того же поставщика, остальные берутся как были. Если в прайсе нет столбца бренда — укажите бренд для всего прайса;
- галочка **«запомнить формат»** сохраняет названия столбцов: похожие прайсы (тот же поставщик, другой город) прочитаются так же;
- ненужный прайс выключается переключателем.

В отчёт попадает минимальная цена конкурента на момент формирования. Цены ниже 10 ₽ и цены в разы ниже остальных по тому же артикулу не берутся.

### Покрытие ценами конкурентов

Вкладка «Почему мало цен» у группы. Сверху — где теряются цены по всем конкурентам сразу и что с этим делать. По каждому конкуренту — путь от товара до цены: товаров → есть кросс «Да» → артикул есть в каком-то прайсе → цена у поставщика из позиционирования → отсеяно → с ценой, и доля продаж в штуках, у которой цена есть. Ниже — что сделать, чтобы цен стало больше: «нет прайса MXGroup — у 52 товаров кросс «Да» есть, цены нет», «нет кроссов «Да» на Kashiyama». «Из них по «Нет»» — сколько цен пришло по кроссам «Нет».

Надёжность цены: у скольких товаров цена только у одного поставщика, насколько дороже ближайший другой поставщик (большой разрыв — повод проверить минимум) и кто чаще даёт минимум.

**Отсев несопоставимого** (галочка в этом блоке, по умолчанию включена): комплект «диски + колодки» против одной детали и цена, отличающаяся от нашей Кат. А в 3 раза и больше (число можно поменять), в сравнение не идут — это ошибка кросса или комплектности. Ячейка цены этого конкурента в отчёте остаётся пустой. Выключите галочку — цифры станут как раньше.

**«Выгрузить дыры в кроссах»** кладёт `Результат/Дыры в кроссах — <ТМ группа>.xlsx`: товары без кросса «Да» по продажам (и кроссы «Нет», у которых есть цена, — кандидаты на проверку), кроссы «Да» без цены с причиной, и отсеянные пары.

**История**: при каждой сборке отчёта по группе запоминаются покрытие ценами, доля в позиционировании, отклонение и ВР — таблица «Как менялось» под блоком. Одна запись в день, файл `Программа/история.json`.

## Окно

Слева список групп из позиционирования. У строки — число товаров, «свой файл», если АЦПКД лежит в папке группы, и причина, если не хватает СБС, Продаж или АЦПКД. Справа сразу аналитика и предпросмотр открытой группы: ВР, корзины отклонения, первые строки.

Быстрого отчёта, основы «АЦПКД + столбцы из ПСТ» и режима «По шаблону / Индивидуально» больше нет: отчёт всегда полный и строится от ПСТ, настройки всегда видны и запоминаются.

- **«Цены и рекомендации»**: слева панель порогов — переключатель «Рекомендованные цены», цель (первый / по списку / все с ценой), коридор, «не понижать больше», «не повышать больше» по сегментам, минимальная ВР, топ продаж и середина с множителем лимитов, округление. Каждый ползунок сразу пересчитывает правую часть: ВР, прибыль и выручку «сейчас → после», сколько поднять и понизить, отклонение от цели до и после, насколько меняем цены, что решило рекомендацию (дошли до цели, упёрлись в лимит, подняли до мин. ВР, уже в коридоре, нет цены) и какие товары сильнее меняют прибыль.
- **«Настройки отчёта»**: подгруппы, фильтры, прайсы, кроссы и источники — одни на все группы. «Сбросить к стандарту» возвращает стандартный набор.
- Справа на «Ценах и рекомендациях»: **где наша цена относительно цели** — доля выручки дороже цели, в коридоре, дешевле и без цены конкурента, сейчас и после; **откуда меняется прибыль** — повышения и снижения отдельно и сколько продаж нужно, чтобы шаг окупился (снижение на p при ВР m окупается ростом продаж на p / (m − p), повышение безопасно, пока продажи падают не больше чем на p / (m + p)); **мы против каждого конкурента** — средняя по выручке разница сейчас и после, с отметкой цели позиционирования.
- **«Снижать, только если окупится ростом продаж до N %»** (по умолчанию 20%): цена не снижается глубже, чем окупит такой рост продаж. 0 — не проверять.
- Если в «Продажах» нет штук (только рубли), топ и середина продаж считаются по рублям — иначе защита топа не срабатывала.
- **«Какую цену конкурента брать»** в «Настройках отчёта»: самая низкая (как раньше), вторая снизу или медиана поставщиков. Склады одного поставщика сначала сводятся к его минимуму. У Brembo и MANN самая низкая цена в среднем на 11–16% ниже медианы рынка.
- Пороги рекомендаций: **«Одни на всех»** или **«Свои у группы»**, и отдельно **«Мои»** / **«Зашитые»**. Правка становится вашими порогами и пишется на диск кнопкой **«Сохранить мои»**. **«К зашитым»** подставляет зашитый набор. Переключатель наборы не стирает.
- Галочка «вставить рек. цены» и «по кому ставить цель» — общие.

Фильтры: оверсток, распродажа и вывод (тип ассортимента R, категория ABC D или столбец «Вывод из ассортимента»), NEW (это тип ассортимента N, не категория ABC «NEW»), остаток, продажи, без МО, без себестоимости, наличие цены конкурента, категории ABC. «Нет остатка и нет в пути» скрывает артикул, только если нет ни остатка, ни товара в пути.

Кроссы: по каждому конкуренту видно, у скольких товаров есть «Да», только «Нет» или кросса нет, и у скольких будет цена. Аналитику можно разбить по ABC, по подгруппам или по обоим. Если «Да» меньше чем у 30% товаров, программа предлагает добрать «Нет».

Рекомендованные цены подгоняют Кат. А к позиционированию. По умолчанию цель — по списку: сначала первый конкурент, если цены нет — следующий. Не понижать больше 10% и не повышать больше лимита сегмента; ВР не опускать ниже 32%; у топа продаж лимиты меньше. В пределах ±3% от цели цену не трогаем. Эти числа и есть общие пороги, пока у группы не заданы свои.

Кнопка **«Проверка папки»** — отдельный файл о том, что нашлось в папке и где ПСТ расходится с АЦПКД.

Кнопка **«Все группы»** делает файл Excel на каждую торговую марку и группу, где нашлись все четыре документа: ПСТ, СБС, Продажи и АЦПКД. Неважно, лежат они в папке группы или во «Входящие». АЦПКД во «Входящие» может быть несколько, по категории: в отчёт группы попадут строки с её брендом и группой. Свой АЦПКД в папке группы важнее. Достаточно одного товара группы в каждом документе. Группы без строки в позиционировании не собираются. Прайс может быть почти пустым — файл всё равно создаётся. В файл попадают пороги так, как выбран переключатель: один набор на всех или свой у группы, из ваших сохранённых или из зашитых. Одна выбранная группа по кнопке «Сформировать отчёт» собирается и без полного набора. `Разбор.txt` при «Все группы» получает блок и по серым строкам, и по группе, чей Excel не сохранился: ошибка одной группы не стирает и не пропускает остальные.

## Что в отчёте

Файл в папке «Результат» называется по торговой марке и группе, например `ADVICS Тормозные диски.xlsx`. В той же папке, не внутри подпапок, лежит `Разбор.txt`: блок на каждую группу из списка слева. Если цен конкурента нет, в блоке одна строка — «Вывод: нет цен для анализа.» Повторная сборка заменяет только блок этой группы и не стирает остальные.

**Полный** отчёт — лист **«Отчет»** (или отдельный лист на каждую подгруппу из позиционирования) и скрытые листы **«Кроссы»**, **«ПСТ»**, **«СБС»** и **«Продажи»**. Выгрузки лежат в том виде, в каком их отдала 1С.

Фильтры программы убирают строки до сборки файла. Строка «Показать / Скрыть» в Excel не пишется: она не пересчитывалась при смене ячейки. Уже сохранённый файл сам не починится — его нужно собрать заново.

**«Кроссы»** скрыт, как и выгрузки. Без оформления и без объединённых ячеек. Строка на наш артикул. Шапка в два этажа: кросс-бренд, под ним выбранные программой кросс-артикулы, поставщики с ценами и «Мин» по этому бренду. «Мин» считается на этом листе. В отчёте цена конкурента записана числом и на «Кроссы» не ссылается. Подгруппа, которой нет в позиционировании, в отчёт не попадает. Столбец конкурента появляется, если цена есть хотя бы у одного товара. Кросс без цены столбец не создаёт. Если себестоимости нет, а СБС план есть, ВР считается от плана.

**Смежная марка.** Зелёный столбец после цен конкурентов, имя — соседняя ТМ. В ячейке минимальная Кат. А из ПСТ: МО в рублях с учётом скидки, среди артикулов с общим номером ОЕМ. Пары только две: ADVICS и AVANTECH на тормозных дисках и колодках, AVANTECH и DOUBLE FORCE на фильтрах. Цена АЦПКД в этот столбец не подставляется. Сам файл ОЕМ цен не содержит, он только связывает артикулы. Если файл не прочитан, столбец всё равно есть, а ячейки пустые: об этом пишет шапка программы и `Разбор.txt`. У остальных групп столбца нет.

«Отчет» — код, наименование, артикул, разновидность, продажи, остаток, ABC, СБС, Кат. А, ВР, суммы, цена и отклонение каждого конкурента. Если включено — рекомендованные цены. Столбцов «Курс», «ГЗ» и «Скидка» на листе нет: эти числа стоят внутри формул. Оформление, фильтр и закрепление только здесь. Суммы и количества — с разделением тысяч.

Листы «ПСТ», «СБС» и «Продажи» повторяют выгрузку. То, что взято оттуда, на отчёте — ссылка по коду товара: лист можно заменить новой выгрузкой с тем же именем и теми же столбцами, и числа обновятся. То, что взято из АЦПКД или прайса, записано числом. СБС за штуку, закупочная цена, Кат. А, ВР, суммы и отклонения считаются формулами в строке отчёта.

**Быстрый** отчёт — короткий «Отчет» и те же скрытые листы выгрузок.

Синий шрифт — исходное значение, его можно править. Чёрный — формула. Заливка отклонения: в пределах допуска без цвета, дальше зелёный или красный (что считать «хорошей» стороной — в настройках группы). ВР ниже минимума — оранжевым. Оформление только на листе отчёта.

Расчёт:

- **Закупочная цена** = цена с листа «ПСТ» × курс. Курс записан числом в формуле. Валюта берётся из столбца ПСТ как есть (U2USD, JPY, CNY, UUSD…); рубли считаются по 1. Если у валюты нет курса, окно предупредит, сколько товаров затронуто;
- **СБС план** = закупочная цена × коэффициент ГЗ. Коэффициент записан числом в формуле;
- **Кат. А** = МО × (1 − скидка). Скидка записана числом в формуле;
- **ВР 1** = 1 − СБС / Кат. А;
- **Сумма продажи** = Продажи, шт × Кат. А (нет штук — сумма продаж в рублях), **Сумма прибыли** = Сумма продажи × ВР 1;
- **Цена конкурента** — минимальная цена на момент формирования, числом. Цены ниже 10 ₽ и цены меньше 10% нормального уровня по тому же артикулу не выводятся: это заглушки вроде 1–2 ₽, а не предложение;
- **В пути, шт** и **Потенциал, шт** (остаток + в пути) появляются сразу после остатка, только если по артикулам отчёта есть товар в пути;
- **Откл** = 1 − наша цена / их цена. Минус — мы дороже;
- **Рек. кат. А** — значение, его можно поправить. Цель по позиционированию в лист не выводится, она нужна только для расчёта рекомендованной цены. Изм. %, рек. МО, ВР рек. и суммы — формулы от неё;
- **Автопарк и ценовой сегмент** — по маркам и моделям из «Разновидности». Справочник правится во вкладке «Настройки», интернет не нужен.

Всё, что считается, — формулы. Итоги в первой строке учитывают фильтр Excel. Кроссы «Нет» — курсивом, кроссы из АЦПКД — серым.
Каталожные столбцы сгруппированы и сворачиваются кнопкой «−» над таблицей.

## Настройки

Вкладка **«Настройки»**: курсы валют, коэффициенты ГЗ, скидки, марки и модели авто (автопарк, сегмент, правый руль),
порог подсказки по кроссам, папка для отчётов, общие пороги рекомендаций и свои пороги групп. Сохраняется в `Программа/настройки.json`
(удалите файл — вернутся зашитые значения). Кнопка «Взять из папки» переносит ГЗ и скидки из выгрузок.

## Структура

```
Запуск.bat                 запуск
main.py                    окно на http://127.0.0.1:47615
Программа/                 код и настройки.json
Данные/Кроссы/             один файл кроссов на всех
Данные/Прайсы/             общие прайсы
Данные/Группы/…            папка на каждую группу бренда
Результат/                 готовые отчёты
Входящие/                  читается, пока в «Группы» ещё нет выгрузок
```
